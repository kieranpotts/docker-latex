= LaTeX Docker images

Docker container images for running LaTeX (TexLive) compilations. Published to https://hub.docker.com/r/kieranpotts/latex[Docker Hub] with multiple variants to suit different use cases.

See the https://hub.docker.com/r/kieranpotts/latex[Docker Hub repository] for usage instructions. The following documentation is for the maintainers of this repository.

== Documentation

=== Requirements

* Docker
* Make
* Git

=== Prerequisites

Make the `run/*` scripts executable:

[source,sh]
----
chmod +x run/*
----

=== Building locally

[source,sh]
----
make build
----

This iterates over all variant directories under `src/`, builds each as a Docker image, and stores the list of built images in `logs/images.txt`.

To build only one variant:

[source,sh]
----
docker build -t kieranpotts/latex:texlive-full -f src/texlive-full/Dockerfile .
----

You can verify the build with:

[source,sh]
----
docker images kieranpotts/latex:texlive-full
----

=== Image variants

One image variant is available at this time.

* `texlive-full` — Ubuntu 24.04 LTS base with the full TexLive package. This is the most commonly used TexLive package and is suitable for most use cases. However, it's a large package. The image size is 2.64GB, and disk usage of a running container is 8.75GB.

Other variants will be added in the future.
